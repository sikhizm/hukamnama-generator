# Usage Examples & Scenarios

## Scenario 1: Default Configuration (Recommended)

### Settings
```
Auto-fit: ON ✓
Size ratio: 1.5×
Line height: 1.62
Justify: ON
```

### Result
- Original text automatically sized at some base size
- Translation automatically sized at 66% of original
- Both shrink proportionally until they fit the canvas
- Perfect for sacred text where original is emphasized

## Overflow Behavior

### What Happens When Text is Too Large?

#### Before (Old System)
```
Original: 80px, Translation: 80px
Result: TEXT SPILLS OUT OF BOX ❌
```

#### After (New System with Clipping)
```
Original: 80px, Translation: 80px
Result: Text clipped to fit box + Warning in console
Console: "Original text overflows by 45px"
Visual: Text stays within red box boundaries ✅
```

### Overflow Detection Example
```typescript
If your settings overflow:
"Original text overflows its panel by 45px"
→ Reduce originalSize by 45px or enable auto-fit

"Translation overflows its panel by 12px"
→ Reduce translationSize by 12px
```

## Tips & Tricks

### Tip 1: The Golden Ratio
For most verse types, **1.5× is optimal**:
- Original feels emphasized without overwhelming
- Translation remains readable
- Works across all social platforms
- Professional appearance

### Tip 2: Combine with Line Height
```
Larger sizes → Reduce line height (1.4-1.5)
Smaller sizes → Increase line height (1.7-1.9)
```

### Tip 3: Font Choice Matters
```
Original (Decorative): Chatrik Uni + 56px
Translation (Readable): Tiro Gurmukhi + 36px
Result: Maximum visual distinction
```

### Tip 4: Auto-fit for Lazy Users
```
Set ratio once → Forget about sizing
Perfect for daily posts → Same visual feel
Works across all presets automatically
```

### Tip 5: Save Your Presets
Copy your favorite settings:
```
typo: {
  autoFit: true,
  originalSizeRatio: 1.65,
  lineHeight: 1.58,
  justify: true,
}
```

## Common Mistakes to Avoid

### ❌ Mistake 1: Using Maximum Everything
```
Original: 80px
Translation: 60px
Line height: 1.9
Result: Text barely fits, looks cramped
Solution: Use auto-fit or reduce sizes
```

### ❌ Mistake 2: Forgetting About Line Height
```
Original: 72px
Line height: 1.3 (too tight)
Result: Characters overlap, illegible
Solution: Use line height ≥ 1.5 with large text
```

### ❌ Mistake 3: Ignoring the Warnings
```
Console: "Original overflows by 30px"
Ignoring it → Text is clipped
Solution: Reduce size by 30px or enable auto-fit
```

### ❌ Mistake 4: Ratio Too Extreme
```
Original: 80px (1.9× ratio)
Translation: 42px (too small, illegible)
Result: Translation unreadable
Solution: Use ratio ≤ 1.5 or larger base size
```

### ✅ Correct Approach
```
Start with defaults (1.5×)
→ Test across platforms
→ Adjust ratio if needed
→ Use auto-fit for consistency
→ Check console for warnings
→ Export at full resolution
```
